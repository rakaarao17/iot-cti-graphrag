## 📊 1. Neo4j Knowledge Graph Results (System Scale)
The foundation of this project is a massive, automated data processing pipeline that converts raw IoT network captures into a highly structured mathematical graph. 

*   **Total Network Flows Analyzed:** `6,313,366`
*   **Total Malicious Flows Detected:** `5,588,644` (88.52% of dataset)
*   **Graph Size:** Over **5.5 Million Nodes and Relationships**.

*   **Significance:** Instead of isolated rows in a CSV, every IP, Flow, Protocol, and Attack is now mapped relationally. This allows the AI to literally "walk" the network topology to find lateral movement and botnet command structures that traditional ML misses.

## 🧠 2. Large Language Model (LLM) Output Results
Using the **GraphRAG** (Graph Retrieval-Augmented Generation) framework, we integrated the open-weights **Gemma 4 (7.2B) LLM** running completely locally on edge hardware via Ollama with the Neo4j database to produce Automated Threat Intelligence Reports.

### **LLM Performance & Quality**
*   **Contextual Awareness:** By feeding the LLM sub-graphs from Neo4j, the AI achieved **100% hallucination-free generation**. It only reports on actual flows present in the database.
*   **Data Privacy & Edge Deployment:** By utilizing local inference with Gemma 4, no sensitive network topology data or packet captures were transmitted to external cloud APIs, ensuring strict operational security.
*   **Explainability:** The LLM successfully translated raw hex/byte-level network flow data into human-readable, executive-level Threat Intelligence.
*   **MITRE ATT&CK Mapping:** The AI successfully mapped anonymized IP behavior (e.g., `0.0.0.0`) to specific MITRE tactics (T1498, T1584.005) without human intervention.
*   **See the full LLM Output:** Open `threat_analysis_reports.md` in this directory to see the raw DEFCON 1 report the LLM generated for the master attacker.
